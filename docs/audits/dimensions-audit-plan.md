## 2. Questions for Oleh

- Q1 — DECIDED 2026-11-23: hero origin never changes (immutable after creation).
- Q2 — DECIDED 2026-11-23: Alien drop chance 0.5% = 50 bp (one config value).
- Q3 — DECIDED 2026-11-23: variant A — base token world = mob's own dimension, not the map's dimension.
- Q4 — DECIDED 2026-11-23: a sold unique instance stays at the trader until the current game day ends; the player can buy it back during that day; after the day the instance is gone forever. The unique template stays in the drop pool.
  - Verified: the game day exists in code (`game-day/game-day.ts`, `progress.day`, event `GAME_DAY_STARTED`; quest generator phase 1).
- Q5 — DECIDED 2026-11-23: uniques are NOT one-of-a-kind. The same unique template can drop again with a different attribute set; the hero can hold several, sell weaker, keep stronger. Unique = fixed identity (key, name, sprite, special skills) + rolled attributes. Supersedes "uniques cannot be duplicated".
  - Unique attributes = two layers (DECIDED 2026-11-24): (1) generated layer: the same attribute generator, the item type's attribute pool, wider bounds than base (unique bounds profile); (2) authored layer: the Creator adds unique attributes to the template, each with min/max; each instance rolls a value inside them. Base attribute rules stay unchanged. Supersedes the 2026-11-18 rule "uniques get no rolled attributes".
  - Default (proposed, not decided): an attribute key in the authored layer is excluded from the generated layer of that instance (no stacking duplicates).
  - DECIDED 2026-11-24: generated-layer bounds = map-level bounds × unique multiplier (one config value; designer sets the number). Early-map unique is weaker than late-map unique.
