## 0. Мета

Зараз з підземелля нічого не випадає: скриня лише «відмикається», а перемога над загоном просто прибирає жетон (`squad.loot` ніхто не читає). Після цього етапу коло замкнене:

```
підземелля → бій → могили → здобич → скриня → здобич → торговець → монети → спорядження
```

Це також закриває рядок чекліста «перше джерело монет».

## 1. Правило (рішення Олега 2026-11-12)

### 1.1 Спільне для скрині й могили

1. **Ціль** — повна скриня або неоглянута могила. Герой стоїть на сусідньому гексі `E` (гекс входу).
2. **Дія** запускається лише з кільця інструментів: **рука → OPEN** для скрині, **око → EYE** для могили. Дія нічого не показує, вона лише запускає подію.
3. **Герой безплатно переходить на гекс цілі.** Об'єкт не зникає: фішка героя стоїть на ньому зверху.
4. **Вільні місця** — сусіди гекса цілі, які одночасно: є на дошці, прохідні, без об'єкта, предмета, істоти чи героя, і не є гексом `E`. Гекс `E` завжди лишається порожнім як вихід.
5. **Кількість здобичі** `n` береться з таблиці здобичі цілі (діапазон `rolls`). Випадає `min(n, кількість вільних місць)`. Зайве відкидається з кінця списку.
6. **Розкладання:** за годинниковою стрілкою, починаючи з першого вільного гекса після `E`. Без випадковості.
7. **Монети** — один стос на один гекс, скільки б їх не було.
8. **Після дії** ціль стає **порожньою**: взаємодіяти не можна, стати на неї не можна. Герой сходить з неї на будь-який вільний сусідній гекс і повернутися вже не може.
9. **Вільних місць нуль** (усі сусіди, крім `E`, зайняті): дія відхиляється до переходу героя з однією причиною `NO_ROOM_FOR_LOOT`. Ціль лишається повною.
10. **Рахує сервер.** Потік випадковості `loot:<id цілі>` від прихованого сіда; клієнт сіда не бачить. Відкрити можна один раз; повтор команди з тим самим `commandId` повертає той самий результат.
11. **Наведення** показує картку об'єкта із загальним описом і одним реченням правила без чисел («здобич розлітається на вільні місця навколо»). Порожня ціль має печатку «порожньо».

Як це робиться за столом: зняти з цілі жетон «повна», поставити фішку героя на ціль, витягти з мішечка стільки жетонів здобичі, скільки каже картка цілі, але не більше, ніж вільних гексів навколо; розкласти за годинниковою стрілкою від гекса, з якого прийшов герой.

### 1.2 Скриня (карта підземелля)

- Дія `OPEN` рукою. Ціна дії — з контенту (типово безплатно).
- Відкрита скриня лишається на карті як перешкода з іншим спрайтом (відкрита кришка).
- Генератор ставить скриню так, щоб у неї було **щонайменше 3 прохідні сусіди без об'єктів**.
- Здобич лежить на карті підземелля, доки герой у ньому. Підземелля свіже на кожен вхід, тож незібране пропадає при виході.

### 1.3 Могила (карта бою)

- Кожен убитий ворог лишає надгробок на гексі, де впав. Гекс із надгробком не є вільним місцем для здобичі сусідніх могил.
- Після перемоги бій переходить у **фазу збирання**: кроки героя безплатні (не коштують ні Волі, ні бойової Волі), пастки вимкнені, вороги відсутні.
- Дія `EYE` оком на сусідню могилу. Безплатна.
- **Вихід з поля бою** — окрема безплатна дія. Після виходу жетон загону прибирається з карти підземелля, гекс стає вільним.
- Незібране на полі бою пропадає. Перед першим у житті героя виходом з незібраною здобиччю гра один раз попереджає (віха в `progress`).
- Поразка: фази збирання немає.
- Відновлення сесії повертає гравця у фазу збирання з тим самим розкладом здобичі.

### 1.4 Таблиці здобичі

```ts
interface LootTable {
  id: LootTableId;
  rolls: [min: number, max: number]; // скільки жетонів витягти
  guaranteed?: LootEntry[]; // завжди випадає (бос)
  entries: { itemKey: ItemKey; weight: number; amount: [number, number] }[];
}
```

- **Таблиця на істоту**, не на загін: `CreatureDefinition.lootTableId`. Це уточнює `architecture/domain-model-plan.md` §5.3, де таблиця стояла на загоні.
- Скриня: `ObjectCapability.container.lootTableId`.
- Початковий контент (числа в контенті, не в коді):

| Ціль                | `rolls` | Склад                                                    |
| ------------------- | ------- | -------------------------------------------------------- |
| Скелет-воїн         | 1–2     | монети (часто), зілля здоров'я, кістяний оберіг          |
| Скелет-лучник       | 1–2     | монети, зілля, сувій (рідко)                             |
| Скелет-король (бос) | 3–4     | гарантовано монети + уламок корони; далі меч, щит, сувій |
| Скриня печери       | 2–4     | монети, зілля, спорядження                               |

- Дерево й камінь отримують `coinPrice` і продаються торговцю.
- Пляшки енергії й мани в таблиці не входять, доки не працюють у бою.

## 4. Тести (мінімум)

**Engine (Vitest)**

- 5 вільних сусідів, `rolls` дає 3 → 3 предмети на перших трьох гексах за годинниковою стрілкою від `E`.
- `rolls` дає 5, вільних 2 → 2 предмети, решта відкинута.
- Гекс `E` ніколи не отримує предмет.
- 0 вільних → `NO_ROOM_FOR_LOOT`, стан не змінено, герой не переміщений.
- Монети: один запис-стос незалежно від кількості.
- Той самий сід і той самий `id` цілі → той самий результат.
- Сусідня могила зменшує кількість вільних місць.
- Порожня ціль: `OPEN` / `EYE` відхилено; крок на неї відхилено.
- `guaranteed` боса випадає першим і не відкидається, доки є хоч одне місце.

**API (інтеграція)**

- Повтор команди з тим самим `commandId` не дублює здобич.
- Відповідь не містить сіда й нерозіграних таблиць.
- Чужий герой → `FORBIDDEN`.

**Playwright**

- Відкрити скриню в печері → герой на гексі скрині → предмети навколо → підібрати → перезавантажити сторінку → предмети в сумці, скриня порожня.
- Перемогти загін → фаза збирання → оглянути могилу → підібрати монети → вийти → жетона загону немає, прохід вільний.
- Перезавантаження посеред фази збирання повертає в неї.
