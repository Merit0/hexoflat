# World Map MVP — набір зразків для огляду

Згенеровано `pnpm --filter @hexoflat/engine samples:worldmap`
(`packages/engine/src/generators/world-map-samples.gen.test.ts`, guard `GEN_SAMPLES=1`).

10 **прийнятих** карт: 3 `FORKED_FRONTIER`, 3 `RIDGE_AND_POCKET`,
2 `OPEN_FIELD_NARROW_PASS`, 2 `LANDMARK_PULL`. Для кожної — `<archetype>-NN.svg`
(схематичний рендер дошки) і рядок у `samples.json` із сидом, архетипом,
метриками валідатора, списком promise-ів та кількістю відхилених спроб до
прийняття.

Це матеріал для приймального огляду Oleh-ом за 14 питаннями
`docs/design/world-map-mvp-generator-v0.1.md` §24 — не автотест.

## Легенда SVG

| Елемент                      | Значення                                                                                                                                      |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Заповнений гекс              | викладений тайл, колір = терен (`OPEN_GROUND`, `STONE_RIDGE`, `FOREST_EDGE`, `BROKEN_GROUND`, `NARROW_PASS`, `POCKET_FLOOR`, `FRONTIER_EDGE`) |
| Золоте кільце (товсте)       | Camp Anchor                                                                                                                                   |
| Зелена крапка                | спавн героя                                                                                                                                   |
| Пунктирний контур            | відкритий шов — куди карта могла б рости                                                                                                      |
| Синє коло + підпис           | Frontier Promise (сила + тип), у Deep Unknown за швом                                                                                         |
| Тонке золоте кільце + підпис | зарезервований слот gameplay-anchor (без ігрової логіки)                                                                                      |

SVG — схематичний (плоскі кольори, без арту тайлів): достатньо, щоб судити
про форму, асиметрію, розгалуження й те, чи тягне край карти до себе.
Справжній вигляд у грі — debug-панель у dev-збірці (`/world/silesia`).

## Регенерація

Детерміновано від сида. Перегенерувати (напр. після зміни секцій/архетипів
_до_ заморозки) — тим самим скриптом; коммітити оновлені SVG + `samples.json`
разом зі зміною генератора.
