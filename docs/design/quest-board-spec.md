## 0. Як працювати

- Одна фаза = один чат, гілку створює Олег. Не комітити.
- Правила квестів живуть лише в `packages/engine` (див. treasure-seeker-plan, Частина А). Цей документ — тільки UI: web отримує проєкцію `QuestBoardView`, надсилає команди `QUEST_ACCEPT / QUEST_ABANDON / QUEST_CLAIM / QUEST_ENTER`, показує відмови (`Refusal`).
- Жодної ігрової логіки (ціна слота, перевірка вимог) у Vue-компонентах: компонент лише відображає те, що прийшло в проєкції.
- Усі тексти — через i18n. Сирий ключ на екрані (`QUEST.SEEKER-1.NAME`) — це баг, і на нього є тест (§9).

## 2. Розкладка

- Ліва частина екрана — **завжди мапа** (R-Q-9).
- Дошка квестів — у **правій панелі** шириною 480px (desktop), padding 16px 16px 12px, вертикальний стек з gap 12px:
  1. Шапка (40px)
  2. Плашка ресурсів (Монети + Воля)
  3. Фільтри
  4. Список груп (займає решту висоти, скролиться всередині)
  5. Рядок статусу (футер)

**Уточнення до R-Q-9 (пропоную вписати в план):** постійний вміст квестів — лише в правій панелі; **тимчасові** поп-апи (деталі квесту, довідка) можуть перекривати край мапи, поки на них наведено або вони закріплені.

## 4. Компоненти

### 4.1 Шапка — `QuestBoardHeader`

Сітка `40px | 1fr | 40px`:

- **ліворуч** — кнопка `?` (40×40, Cinzel 20px). Наведення / фокус → поп-ап довідки (§4.8). Тап / клік — закріпити або відкріпити.
- **центр** — заголовок `Quests` (Cinzel 22px, `gold.text`, по центру).
- **праворуч** — кнопка закриття ✕ (40×40), `aria-label="Close quest board"`.

### 4.2 Плашка ресурсів

Одна плашка на всю ширину: зліва лейбл `WILL`, справа ● монети (`gold`) і `38 / 50` Волі; під ними смужка Волі 6px.
Окремої секції «Quest slots» **немає**: зайнятість слотів показана в заголовку групи «My quests» (`1 of 3 slots`), доплата — у ціні на кнопці.

### 4.3 Фільтри — `QuestFilterChips`

`All · Gathering · Combat · Learning · Expedition`, у кожного лічильник квестів (без завершених одноразових). Таблетка 32px, `aria-pressed`. Активна — рамка й текст кольору категорії (`All` — `gold.text`). Фільтр діє на всі групи. Стан фільтра — UI-стан (Pinia/composable), не рушій.

### 4.4 Групи

| Група                          | Що містить                                                                                 | Порожній стан                                                                              |
| ------------------------------ | ------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------ |
| **MY QUESTS** · `n of 3 slots` | взяті квести (порядок взяття)                                                              | пунктирна плашка «No quest taken yet. Take one below — it moves up here with its counter.» |
| **ON THE BOARD** · `n quests`  | доступні                                                                                   | «Nothing new for this filter.»                                                             |
| **LOCKED** · `n quests`        | закриті вимогами; група згортається (шеврон, `aria-expanded`), за замовчуванням розгорнута | не показується, якщо порожня                                                               |

Завершені одноразові квести на дошці не показуються.

### 4.5 Рядок квесту — `QuestRow`

Висота **60px** для всіх станів. Зовнішня сітка: `1fr | 96px` (тіло-кнопка | колонка дії). Тіло — кнопка з сіткою `40px | 1fr | 56px`, gap 12px:

| Колонка | Вміст                                                                                                                                                                         |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 40px    | плитка 40×40 з іконкою категорії (колір категорії)                                                                                                                            |
| 1fr     | рядок 1: назва (16px 700, обрізання `…`) + маркер виду: ⟳ повторюваний / `1×` одноразовий. Рядок 2: мета-текст 13px. Рядок 3 (лише взятий лічильниковий): смужка прогресу 4px |
| 56px    | головна нагорода: іконка 18px + коротке значення (`×5`, `30`); якщо нагород кілька — `+N`                                                                                     |
| 96px    | колонка дії (§4.6)                                                                                                                                                            |

Мета-текст за станом:

- доступний лічильник — `Cut 10 trees`
- доступна експедиція — `10 steps · 1 Will per step`
- взятий — `Cut trees · 4 / 10`
- ціль досягнута — `Goal reached — claim it` / `Chest found — claim it` (колір `gold`)
- закритий — невиконані вимоги через `·` (колір `#C9A27A`), рядок з прозорістю 0.62

Рамка рядка: звичайний `line.soft`; взятий — колір категорії; ціль досягнута — `gold`; наведений/відкритий — `gold.dim`, фон `bg.raised`.

### 4.6 Колонка дії (96×40)

| Стан квесту                   | Вміст                                                                                                                                                                             |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| доступний                     | кнопка **лише з ціною**: символ валюти + число. ◆ Воля, ● монети. Якщо платиться і монетами, і Волею (доплата за слот) — обидві: `● 10 ◆ 5`. Без ціни — `◆ 0`. Слова «Take» немає |
| доступний, але не можна взяти | та сама кнопка, `disabled`, сіра; `title` = причина                                                                                                                               |
| взятий лічильник              | лічильник `4 / 10` у рамці (не кнопка)                                                                                                                                            |
| взята експедиція              | кнопка `Enter`                                                                                                                                                                    |
| ціль досягнута                | золота кнопка `Claim`                                                                                                                                                             |
| закритий                      | замок + `Locked`                                                                                                                                                                  |

`aria-label` кнопки ціни: `Take Woodcutter for 5 Will` / `… for 10 coins and 5 Will`.
Ціна на кнопці = вхід квесту + доплата за наступний слот (обчислює рушій і віддає в проєкції як `takeCost: Cost`).

### 4.7 Деталі квесту — `QuestDetailsPopover`

**Коли:** наведення на рядок (`mouseenter`), фокус тіла рядка (Tab), або тап/клік по тілу рядка (закріплює; повторний клік або ✕ — відкріплює). Одночасно відкрита одна картка.

**Де:** **зліва від рядка**: `position: absolute; right: 100%`, ширина 400px, праворуч невидимий «місток» 26px (padding-right контейнера), щоб миша дійшла до картки, не закривши її.

- рядки 1–4 списку: верх картки на рівні верху рядка;
- рядки 5+: низ картки на рівні низу рядка (не вилазить за екран).
  Картка не змінює висоту списку.

**Вміст згори вниз:**

1. Назва (Cinzel 18px) + теги `Gathering · Repeatable · done 2×`; у закріпленому стані — ✕ (32×32).
2. Опис (15px).
3. Сітка `84px | 1fr` з лейблами великими літерами:
   - **GOAL** — текст цілі; для взятого — смужка 6px + `4 / 10`; для експедиції — три клітинки `steps` / `Will per step` / `Will per step back` + рядок «Count the Will for the whole trail before you enter.»
   - **REQUIRES** (якщо є) — кожна вимога з ✓ (`#8FCB9A`) або ✗ (`#F2B3A2`).
   - **REWARD** — кожна нагорода окремою плашкою 30px: іконка + `5 × Axe` / `30 Coins`.
   - **TO TAKE** — розписана ціна: `Entry 20 + 2nd quest slot +5 = 25 Will · 10 coins` або `Free`. Для взятого — **TAKEN**: «In your quests. Abandoning gives no Will back.»
4. Причина відмови (якщо є) у плашці `danger`, `role="status"`.
5. Кнопки праворуч: `Abandon` (лише взятий) · головна дія:
   - доступний → **`Start`** (= `QUEST_ACCEPT`)
   - ціль досягнута → `Claim reward`
   - взята експедиція → `Enter the trail`

Тексти причин (з кодів `Refusal`):

| Код                                   | Текст                                                          |
| ------------------------------------- | -------------------------------------------------------------- |
| `QUEST_SLOTS_FULL`                    | All 3 quest slots are in use. Finish or abandon a quest first. |
| `INSUFFICIENT_WILL`                   | Not enough Will: you need {need}, you have {have}.             |
| `INSUFFICIENT_COINS` (новий, див. §6) | Not enough coins: you need {need}, you have {have}.            |
| `REQUIREMENTS_NOT_MET`                | Locked: {список невиконаних вимог}                             |
| `BAG_FULL` (на Claim)                 | Your bag is full. Free {n} slots to take the reward.           |

### 4.8 Довідка — `QuestBoardHelp`

Поп-ап під кнопкою `?`, ширина 448px (на всю панель), той самий стиль, що й деталі. Заголовок «How the quest board works», пункти:

- **Take** a quest and it moves to My quests. Its counter grows as you play — every tree, stone or enemy counts.
- **Up to 3 quests** at once. The first slot is free, the second costs +5 Will, the third +10. Take quests you can do on the same road.
- **Claim** the reward when the goal is reached. Repeatable quests (⟳) come back to the board; one-time quests (1×) close for good.
- **Expeditions** cost Will to enter and for every step. Count the Will for the whole trail before you go.
- **Abandon** frees the slot, but the Will you paid is not returned.
- (сірим) Hover a quest to see its details. On touch screens, tap it.

Числа слотів (+5/+10) беруться з контенту (`questSlots.extraCost`), не захардкоджені в тексті.

### 4.9 Рядок статусу (футер)

Текст по центру, 14px `text.muted`, **без рамки й фону** — лише лінія-роздільник зверху (`border-top: 1px solid line`), `role="status" aria-live="polite"`.
Початковий текст: «Hover a quest to see its details. On touch screens, tap it.» Далі — останні події з доменних подій: `Taken: Woodcutter · −5 Will`, `Reward: 5 × Axe · quest is back on the board`, `Abandoned: … · no Will back`.

## 6. Дані (проєкція з рушія)

```ts
interface QuestBoardView {
  will: { value: number; cap: number };
  coins: number;
  slots: { used: number; max: number; nextSurcharge: number };
  quests: QuestRowView[];
}

interface QuestRowView {
  id: string;
  nameKey: string;
  descKey: string;
  category: 'gather' | 'combat' | 'learn' | 'exp'; // нове поле QuestDefinition.category
  repeat: 'once' | 'repeatable';
  status: 'available' | 'active' | 'complete' | 'locked';
  objective:
    | { kind: 'count'; verbKey: string; unitKey: string; goal: number; progress?: number }
    | { kind: 'expedition'; steps: number; stepCost: number; backCost: number; found?: boolean };
  requirements: { labelKey: string; params?: object; ok: boolean }[];
  rewards: RewardView[]; // перша — головна (у рядку)
  takeCost?: CostView; // лише для available: вхід + доплата слота
  costBreakdown?: { entry: CostView; slotSurcharge: number; slotOrdinal: number };
  refusal?: Refusal; // чому не можна виконати головну дію зараз
  timesDone: number;
}
```

Зміни в моделі (доповнення до Частини А плану):

- `QuestDefinition.category` — для фільтрів та іконки.
- `accept: Cost` уже підтримує кілька ресурсів; UI має показувати і Волю, і монети. Додати код відмови `INSUFFICIENT_COINS`, якщо його ще немає в спільному `Refusal`.
- Проєкцію рахує рушій (селектор `selectQuestBoard(state, content)`), web її лише рендерить.

## 8. Доступність

- Тіло рядка — справжня `<button>` з `aria-expanded` і `aria-label` «{name}, {meta}. Show details.»; кнопка дії — окрема `<button>`.
- Деталі: `<section aria-label="{name} details">`; Esc закриває закріплену картку і повертає фокус на рядок.
- Наведення не є єдиним способом: фокус і клік відкривають ті самі деталі.
- Контраст тексту ≥ 4.5:1 (перевірені пари в §3). Категорії розрізняються не лише кольором — у кожної своя іконка.

## 10. Ручне приймання

- **А1** Відкрити дошку з 1 взятим і 5 доступними квестами — без прокрутки видно всі, взятий нагорі з лічильником.
- **А2** Усі рядки однакової висоти, іконки, нагороди й кнопки стоять у стовпчиках.

- **А6** Пройти дошку лише клавіатурою (Tab, Enter, Esc).
- **А7** На телефоні (390×844) все робиться тапами, нічого не перекриває мапу назавжди.
- **А8** Перемкнути мову — жодного сирого ключа.
