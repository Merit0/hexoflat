# ItemTooltip — специфікація підказки предмета (hexoflat)

Макет (полотно): https://claude.ai/artifact/4fmQWaTJisqFpwYU8qFvxe
Іконки: `apps/web/src/components/gui/icons/item-icons.ts`. Промпти для генерації арту: `docs/design/item-tooltip/item-tooltip-image-prompts.md`.

## Рішення

- Один і той самий блок-підказка на наведення на БУДЬ-ЯКИЙ предмет: у сумці (inventory board) і в слотах спорядження. Не пов'язано з тултіпом Will-токена.
- Форма: **A · Гекс-герб** — верхній край зведений у вістря (30px), медальйон-гекс з іконкою сидить на вістрі й виходить за рамку, прямі боки, зрізані нижні кути (18px). Заголовок по центру.
- Прозорість оправи (E1–E3) — опційно пізніше. Рекомендовано E1 «згасаюча оправа» (рамка кольору рідкості яскрава вгорі → прозора внизу) для легендарних/міфічних.
- Фізична гра: кожна секція переноситься на друковану картку предмета; прозорість лише в цифровій версії.

## Секції (порожні не рендеряться)

| #   | Секція                                                                                     | Дані зараз                                            |
| --- | ------------------------------------------------------------------------------------------ | ----------------------------------------------------- |
| 1   | Заголовок: медальйон, рядок рідкості + бейдж «НАДІТО», назва (колір рідкості), тип         | `rarity`, `title`, `group`, `equipSlot`               |
| 2   | Головна цифра (38px) + чип порівняння ▲/▼ з надітим                                        | `weapon.damageMin/Max`, `attackMultiplier`, `defense` |
| 3   | Базова властивість (сірим)                                                                 | немає в контенті                                      |
| 4   | ВЛАСТИВОСТІ — бонуси (блакитний, число яскравіше)                                          | немає в контенті                                      |
| 5   | УМІННЯ / ДІЯ — картка з назвою, бірюзовою плашкою ціни у Волі, описом                      | немає в контенті                                      |
| 6   | Можливості — чипи (Рубати, Копати, Блок, Атака)                                            | `capabilities.can*`                                   |

## Візуальні токени

- Фон тіла `#14120E`, фон сторінки `#0D0C0A`, нижня смуга `#0E0C09`, лінії `#2E281F`/`#2A241C`.
- Текст `#E8E0CF`, приглушений `#A39886`, художній `#BFA77C`.
- Рідкість: basic `#A8A39A`, common `#EDE6D6`, rare `#6AAEF5`, legend `#F2A93B`, mythic `#D08CFF`.
- Значення: Воля `#59D3C2`, серце `#E0675A`, бонус `#9CC2F5`, краще `#7BD88F`, гірше `#F08A7A`.
- Шрифти: Alegreya SC (назви), Alegreya Sans (текст) — обидва з кирилицею.
- Ширина 360px. Рамка: колір рідкості з альфою 0.55–0.6 + гекс-заклепки.

## Інструкція для Claude Code (гілку створює Олег)

1. `packages/engine`: чиста `resolveItemTooltip(key, { equipped, compareWith? })` поверх `resolveInventoryView` → модель `ItemTooltipView`, кожна секція або є, або `undefined`. Дельту ▲/▼ рахує вона (середній урон для зброї, захист для броні).
2. `apps/web/src/components/gui/item-tooltip/item-tooltip.vue` — лише рендер моделі; кольори рідкості як CSS-змінні; іконки з `item-icons.ts`.
3. Форма A: двошаровий `clip-path` (зовнішній шар = колір рамки, внутрішній = тіло) — для непрозорого варіанту. Медальйон абсолютно поверх вістря, поза clip.
4. Один шар підказки на сцену інвентарю: composable `useItemTooltip()` (`hoveredItemId` + rect клітинки). `inventory-token.vue` і `equip-token.vue` викликають його на `mouseenter`/`focus`, ховають на `mouseleave`/`blur`. `<Teleport to="body">`, `pointer-events: none`, справа від клітинки +16px, якщо не влазить — зліва; по вертикалі в межах вікна (24px); затримка ~120мс; приховано під час drag (`use-inventory-drag`).
5. `token-details-panel.vue` — перевести на ту саму модель або прибрати.
6. Тести: Vitest на мапер (усі групи й рідкості); Playwright — наведення на предмет у сумці та на надітий → видно `data-testid="item-tooltip"` з правильною назвою.
7. Окрема фаза контенту для секцій 3–5: у Zod-схему `implicit`, `affixes[]`, `skills[] { name, willCost, desc }`, `flavor`; підняти `CONTENT_VERSION`.

## Якщо робити прозору оправу (E1)

- Рамку малювати SVG-контуром поверх тіла, точки будувати з реальних розмірів (`ResizeObserver`). Двошаровий clip-path з прозорим тілом не працює — крізь тіло видно кольоровий шар.
- Тіло: `clip-path` + `backdrop-filter: blur()`.
- Без `filter: drop-shadow` на предках — він вимикає розмиття фону; тінь окремим розмитим SVG-шаром.
