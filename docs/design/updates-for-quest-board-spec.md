## 0. Як працювати

- Одна фаза = один чат, гілку створює Олег. Не комітити.
- Правила квестів живуть лише в `packages/engine` (див. treasure-seeker-plan, Частина А). Цей документ — тільки UI: web отримує проєкцію `QuestBoardView`, надсилає команди `QUEST_ACCEPT / QUEST_ABANDON / QUEST_CLAIM / QUEST_ENTER`, показує відмови (`Refusal`).
- Жодної ігрової логіки (ціна слота, перевірка вимог) у Vue-компонентах: компонент лише відображає те, що прийшло в проєкції.
- Усі тексти — через i18n. Сирий ключ на екрані (`QUEST.SEEKER-1.NAME`) — це баг, і на нього є тест (§9).

## 2. Розкладка

- Ліва частина екрана — **завжди мапа** (R-Q-9).
- Дошка квестів — у **правій панелі** шириною 480px (desktop), padding 16px 16px 12px, вертикальний стек з gap 12px:
  1. Шапка (50px)
  2. Плашка статусу (взяті квести, монети, Воля)
  3. Фільтри
  4. Список груп (займає решту висоти, скролиться всередині)
  5. Рядок статусу (футер)

**Уточнення до R-Q-9 (пропоную вписати в план):** постійний вміст квестів — лише в правій панелі; **тимчасові** поп-апи (деталі квесту, довідка) можуть перекривати край мапи, поки на них наведено або вони закріплені.

## 3. Візуальний стиль і токени (стиль «темне золото», затверджений 2026-11-12)

Характер: темні сталево-графітові картки, бронзово-золоті акценти, золоті кнопки з гострими кінцями, шестикутні емблеми, шрифт із засічками для назв і чисел. Без емодзі, без кольорових смуг зліва карток, без барвистих градієнтів — золото лише на акцентах.

Шрифти:

- **Cormorant Garamond 700** — заголовок «Quests» (38px), назви квестів (21px; у поп-апі 26px), числа (ціни, лічильники, ресурси, нагороди), текст кнопок.
- **Alegreya Sans 400/700** — описи, мета-рядки, підписи.
- **Великими літерами з розрядкою** (0.08–0.14em, 10–12px) — лише теги (`REPEATABLE`, `ONE-TIME`), підписи груп і лейбли полів (GOAL, REWARD…), фільтри.

Форми:

- Картка — радіус 10px; поп-ап — 12px; плашки нагород і вторинні кнопки — 8px; фільтри і плашка статусу — повністю заокруглені.
- Золота кнопка — шестикутник, витягнутий по горизонталі: `clip-path: polygon(11px 0, calc(100% - 11px) 0, 100% 50%, calc(100% - 11px) 100%, 11px 100%, 0 50%)` + `inset 0 1px 0 rgba(255,255,255,.45), inset 0 -2px 0 rgba(0,0,0,.25)`.
- Кнопки `?` / ✕ — шестикутник із пласким верхом 48×44, рамка 2px (зовнішній шар) + градієнтне нутро.
- Емблема — шестикутник із гострим верхом 46×52, бронзова рамка 2px.
- Фокус для фігур із `clip-path` — `filter: drop-shadow(0 0 2px #FFE7A8) drop-shadow(0 0 6px #C9A04E)` на обгортці (`:focus-within`), бо `outline` обрізається.

Тач-цілі ≥ 40px.

Іконки емблем — за полем контенту `QuestDefinition.icon` (`axes`, `stones`, `book`, `skull`, `compass`, `leaf`, …), не за категорією. Фінальні іконки — з набору `ui/item-icons.ts` / редизайну UI.

## 4. Компоненти

### 4.1 Шапка — `QuestBoardHeader`

Сітка `48px | 1fr | 48px`, висота 50px:

- **ліворуч** — сталева шестикутна кнопка `?` (48×44, Cormorant 26px). Наведення / фокус → поп-ап довідки (§4.8). Тап / клік — закріпити або відкріпити. Відкрита — рамка стає `gold.line`.
- **центр** — заголовок `Quests` (Cormorant 38px, `gold.title`), по обидва боки тонкі лінії до 90px, що згасають назовні (`transparent → #B8913F`).
- **праворуч** — сталева шестикутна кнопка ✕ (48×44), `aria-label="Close quests"`.

### 4.2 Плашка статусу

Таблетка по центру, 40px заввишки, `bg.pill`, рамка `line`, три частини через вертикальні роздільники 1×20px:

1. іконка планшета з галочкою (золота) + «Quests taken» + **`1 / 3`** (Cormorant 20px);
2. ● монети (Cormorant 20px, `gold.title`);
3. ◆ Воля `38` + дрібне `/ 50`.
   Окремої великої секції слотів і смужки Волі **немає**. Доплата за слот — у ціні на кнопці.

### 4.3 Фільтри — `QuestFilterChips`

`ALL · GATHERING · COMBAT · LEARNING · EXPEDITION` по центру, у кожного лічильник квестів (без завершених одноразових). Таблетка 30px, 12px великими з розрядкою, `aria-pressed`. Неактивна — рамка `line`, текст `text.label`; активна — рамка `#C9A04E`, текст `gold.title`, фон `rgba(201,160,78,.14)`. Фільтр діє на всі групи. Стан фільтра — UI-стан (Pinia/composable), не рушій.

### 4.4 Групи

| Група                         | Що містить                                                                                   | Порожній стан                                                                                        |
| ----------------------------- | -------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------- |
| **MY QUESTS** · `n of 3`      | взяті квести (порядок взяття)                                                                | пунктирна плашка по центру «No quest taken yet. Take one below — it moves up here with its counter.» |
| **ON THE BOARD** · `n quests` | доступні                                                                                     | «Nothing new for this filter.»                                                                       |
| **LOCKED** · `n quests`       | закриті вимогами; група згортається (шеврон, `aria-expanded`), **за замовчуванням згорнута** | не показується, якщо порожня                                                                         |

Заголовок групи: підпис 12px великими з розрядкою (`#B7AE9E`) → тонка бронзова лінія, що згасає (`#4A4232 → transparent`) → лічильник праворуч.
Завершені одноразові квести на дошці не показуються.

### 4.5 Рядок квесту — `QuestRow`

Картка висотою **64px** для всіх станів (у референсі ~150px; скорочено, щоб три групи й фільтри вміщалися на екрані 840px; опис квесту — у деталях). Зовнішня сітка: `1fr | 104px` (тіло-кнопка | колонка дії). Тіло — кнопка з сіткою `48px | 1fr | 58px`, gap 12px:

| Колонка | Вміст                                                                                                                                                                                                                                                          |
| ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 48px    | бронзова шестикутна емблема 46×52 з іконкою квесту                                                                                                                                                                                                             |
| 1fr     | рядок 1: назва (Cormorant 21px, обрізання `…`) + тег-таблетка `REPEATABLE` / `ONE-TIME` (18px, рамка `#4A5057`, 10px великими). Рядок 2: мета-текст 14px `text.label`. Рядок 3 (лише взятий лічильниковий): смужка прогресу 4px (`#C9A04E`, повна — `#F0C060`) |
| 58px    | головна нагорода після вертикальної лінії `#343A40` (34px): іконка 20px + `×5` (Cormorant 19px); якщо нагород кілька — під числом дрібне `+N more`                                                                                                             |
| 104px   | колонка дії (§4.6)                                                                                                                                                                                                                                             |

Мета-текст за станом:

- доступний лічильник — `Cut 10 trees`
- доступна експедиція — `10 steps · 1 Will per step`
- взятий — `Cut trees · 4 / 10`
- ціль досягнута — `Goal reached — claim it` / `Chest found — claim it` (колір `#F0C060`)
- закритий — невиконані вимоги через `·` (колір `#C9A27A`)

Рамка картки: звичайна `line.card`; взятий — `line.active`; наведена/відкрита або ціль досягнута — `#C9A04E` + `gold.glow`. Закрита картка — прозорість 0.6.

### 4.6 Колонка дії (104×40)

| Стан квесту                   | Вміст                                                                                                                                                                                                                               |
| ----------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| доступний                     | золота кнопка з гострими кінцями **лише з ціною**: символ валюти + число (Cormorant 19px). ◆ Воля, ● монети. Якщо платиться і монетами, і Волею (доплата за слот) — обидві: `● 10 ◆ 5`. Без ціни — `◆ 0`. Слова «Take/Accept» немає |
| доступний, але не можна взяти | та сама форма, `disabled`-градієнт; `title` = причина                                                                                                                                                                               |
| взятий лічильник              | лічильник `4 / 10` (Cormorant 19px, `gold.title`) у темній фігурі тієї ж форми з рамкою `#4A5057` (не кнопка)                                                                                                                       |
| взята експедиція              | золота кнопка `Enter`                                                                                                                                                                                                               |
| ціль досягнута                | яскраво-золота кнопка `Claim` (`gold.claim`)                                                                                                                                                                                        |
| закритий                      | замок + `LOCKED` (13px великими, `#8F8A80`)                                                                                                                                                                                         |

`aria-label` кнопки ціни: `Take Woodcutter for 5 Will` / `… for 10 coins and 5 Will`.
Ціна на кнопці = вхід квесту + доплата за наступний слот (обчислює рушій і віддає в проєкції як `takeCost: Cost`).

### 4.7 Деталі квесту — `QuestDetailsPopover`

**Коли:** наведення на рядок (`mouseenter`), фокус тіла рядка (Tab), або тап/клік по тілу рядка (закріплює; повторний клік або ✕ — відкріплює). Одночасно відкрита одна картка.

**Де:** **зліва від рядка**: `position: absolute; right: 100%`, ширина 400px, праворуч невидимий «місток» 26px (padding-right контейнера), щоб миша дійшла до картки, не закривши її.

- рядки 1–4 списку: верх картки на рівні верху рядка;
- рядки 5+: низ картки на рівні низу рядка (не вилазить за екран).
  Картка не змінює висоту списку.

**Оформлення:** фон `bg.card` (`#1F2327 → #17191C`), рамка `#B8913F`, радіус 12px, тінь `0 0 0 1px rgba(201,160,78,.18), 0 0 22px rgba(201,160,78,.12), 0 18px 40px rgba(0,0,0,.6)`, padding 16×18.

**Вміст згори вниз:**

1. Назва (Cormorant 26px, `gold.title`) + теги великими `GATHERING · REPEATABLE · DONE 2×`; у закріпленому стані — ✕ (32×32).
   Під ними золота лінія, що згасає праворуч.
2. Опис (15px, `text.body`).
3. Сітка `84px | 1fr` з лейблами великими літерами:
   - **GOAL** — текст цілі; для взятого — смужка 6px + `4 / 10`; для експедиції — три клітинки `steps` / `Will per step` / `Will per step back` + рядок «Count the Will for the whole trail before you enter.»
   - **REQUIRES** (якщо є) — кожна вимога з ✓ (`#8FCB9A`) або ✗ (`#F2B3A2`).
   - **REWARD** — кожна нагорода окремою плашкою 32px (`bg.sunken`, рамка `line`): іконка + `5 × Axe` / `30 Coins`.
   - **TO TAKE** — розписана ціна: `Entry 20 + 2nd quest slot +5 = 25 Will · 10 coins` або `Free`. Для взятого — **TAKEN**: «In your quests. Abandoning gives no Will back.»
4. Причина відмови (якщо є) у плашці `danger`, `role="status"`.
5. Кнопки праворуч: `Abandon` (лише взятий; прозора, рамка `#4A5057`, Cormorant 18px) · головна дія — золота кнопка з гострими кінцями 42px, мін. ширина 132px, Cormorant 21px:
   - доступний → **`Start`** (= `QUEST_ACCEPT`)
   - ціль досягнута → `Claim reward`
   - взята експедиція → `Enter the trail`

Тексти причин (з кодів `Refusal`):

| Код                                   | Текст                                                          |
| ------------------------------------- | -------------------------------------------------------------- |
| `QUEST_SLOTS_FULL`                    | All 3 quest slots are in use. Finish or abandon a quest first. |
| `INSUFFICIENT_WILL`                   | Not enough Will: you need {need}, you have {have}.             |
| `INSUFFICIENT_COINS` (новий, див. §6) | Not enough coins: you need {need}, you have {have}.            |
| `REQUIREMENTS_NOT_MET`                | Locked: {список невиконаних вимог}                             |
| `BAG_FULL` (на Claim)                 | Your bag is full. Free {n} slots to take the reward.           |

### 4.8 Довідка — `QuestBoardHelp`

Поп-ап під кнопкою `?`, ширина 448px (на всю панель), той самий стиль, що й деталі. Заголовок «How quests work» (Cormorant 22px, `gold.title`), ключові слова пунктів жирні `text`, пункти:

- **Take** a quest and it moves to My quests. Its counter grows as you play — every tree, stone or enemy counts.
- **Up to 3 quests** at once. The first slot is free, the second costs +5 Will, the third +10. Take quests you can do on the same road.
- **Claim** the reward when the goal is reached. Repeatable quests come back to the board; one-time quests close for good.
- **Expeditions** cost Will to enter and for every step. Count the Will for the whole trail before you go.
- **Abandon** frees the slot, but the Will you paid is not returned.
- (сірим) Hover a quest to see its details. On touch screens, tap it.

Числа слотів (+5/+10) беруться з контенту (`questSlots.extraCost`), не захардкоджені в тексті.

### 4.9 Рядок статусу (футер)

Текст по центру, 14px `text.label`, **без рамки й фону** — лише лінія-роздільник зверху, що згасає до країв (`transparent → #6B5A33 → transparent`), `role="status" aria-live="polite"`.
Початковий текст: «Hover a quest to see its details. On touch screens, tap it.» Далі — останні події з доменних подій: `Taken: Woodcutter · −5 Will`, `Reward: 5 × Axe · quest is back on the board`, `Abandoned: … · no Will back`.

```ts
  category: 'gather' | 'combat' | 'learn' | 'exp'; // нове поле QuestDefinition.category
  icon: string; // нове поле QuestDefinition.icon — емблема картки
  repeat: 'once' | 'repeatable';
  status: 'available' | 'active' | 'complete' | 'locked';
  objective:
    | { kind: 'count'; verbKey: string; unitKey: string; goal: number; progress?: number }
    | { kind: 'expedition'; steps: number; stepCost: number; backCost: number; found?: boolean };
  requirements: { labelKey: string; params?: object; ok: boolean }[];
  rewards: RewardView[]; // перша — головна (у рядку)
  takeCost?: CostView; // лише для available: вхід + доплата слота
  costBreakdown?: { entry: CostView; slotSurcharge: number; slotOrdinal: number };
  refusal?: Refusal; // чому не можна виконати головну дію зараз
  timesDone: number;
}
```

Зміни в моделі (доповнення до Частини А плану):

- `QuestDefinition.category` — для фільтрів; `QuestDefinition.icon` — для емблеми картки.
- `accept: Cost` уже підтримує кілька ресурсів; UI має показувати і Волю, і монети. Додати код відмови `INSUFFICIENT_COINS`, якщо його ще немає в спільному `Refusal`.
- Проєкцію рахує рушій (селектор `selectQuestBoard(state, content)`), web її лише рендерить.

## 8. Доступність

- Тіло рядка — справжня `<button>` з `aria-expanded` і `aria-label` «{name}, {meta}. Show details.»; кнопка дії — окрема `<button>`.
- Деталі: `<section aria-label="{name} details">`; Esc закриває закріплену картку і повертає фокус на рядок.
- Наведення не є єдиним способом: фокус і клік відкривають ті самі деталі.
- Контраст тексту ≥ 4.5:1 (перевірені пари в §3). Категорії розрізняються не лише кольором — у кожної своя іконка.

## 10. Ручне приймання

- **А1** Відкрити дошку з 1 взятим і 5 доступними квестами — без прокрутки видно всі, взятий нагорі з лічильником.
- **А2** Усі рядки однакової висоти, іконки, нагороди й кнопки стоять у стовпчиках.
- **А3** Навести на рядок — зліва картка деталей; перевести мишу на картку — вона не зникає; натиснути `Start` — квест узятий.
- **А4** Ціни на кнопках збігаються з «To take» у деталях; після взяття першого квесту ціни інших зросли на +5.
- **А5** Взяти третій квест, навести на четвертий — видно «All 3 quest slots are in use…».
- **А6** Пройти дошку лише клавіатурою (Tab, Enter, Esc).
- **А7** На телефоні (390×844) все робиться тапами, нічого не перекриває мапу назавжди.
- **А8** Перемкнути мову — жодного сирого ключа.
