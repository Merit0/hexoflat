# Hero Details — вкладка «Герой» (специфікація для Claude Code)

Макет: https://claude.ai/artifact/4fmQWaTJisqFpwYU8qFvxe → дошка **«Герой D · A+C у стилі гри»** (низ полотна).
Гілка: `implement-hero-details-board` (створена Олегом). Не комітити — Олег комітить сам.

## Головне правило

На вкладці «Герой» **немає нічого математичного**: жодних таблиць множення, «класу», «Залу Знань», задач.
Прогрес у задачах впливає на героя лише непрямо — через ігрові ранги характеристик (Фаза 2), які гравець бачить як «Сила», «Стійкість» тощо.

## Фаза 1 — UI вкладки (робити зараз)

### Структура (зверху вниз)

1. **Шапка** — темна панель з радіусом 16px:
   - гекс-портрет 104×118 (`/hero-asssets/human-hex.png` — той самий, що в центрі `hero-equip-board.vue`; винести шлях у спільну константу);
   - ім'я (`heroStore.hero.name`), рядок рангу розвідника `III · <назва рангу>` (`getScoutProgress(heroSteps)`);
   - чипи: локація (`heroLocation`, як зараз). Чип «Рівень N» — **сховати**, поки немає джерела рівня.
2. **Ряд життєвих показників** — 3 сланцеві клітинки (як клітинки інвентаря):
   - **Серця**: іконки сердець з половинками, `currentHealth / maxHealth` (половина серця = 0.5);
   - **Щити**: 6 гекс-гнізд, заповнені = кількість щитів. Джерела кількості щитів поза боєм зараз немає → поки показувати `0 / 6` і лишити TODO;
   - **Воля**: зображення `/board-assets/will-icon-image.png` + `knowledge.current / knowledge.capacity`.
3. **Сітка 2×2 характеристик**: Атака, Захист, Поштовх, Вантаж (`carriedWeightKg / carryCapacityKg` з `hero-inventory-store`). Поштовх — сховати плитку, поки немає поля сили.
4. **Перемикач «Стан / Шлях»** (бордовий активний, як головні вкладки; кнопки ≥44px висотою, `aria-pressed`).
   - **Стан** — список рядків «назва · звідки · значення»: Атака, Захист, Крок по мапі (Воля за гекс), Монети, Перемоги, Віра (поки статична, як зараз).
   - **Шлях** — картки з прогрес-баром: Розвідник (кроки до наступного рангу, як у нинішньому поповері). Картки Сила / Стійкість / Витримка Волі — лише у Фазі 2.
5. **Нижня смуга-підказка** в стилі `inventory-hint`: «Наведи на характеристику — побачиш, звідки вона».

### Стиль

- Палітра: фон `#15191B`, клітинки `#29333A` + рамка `#3A474E`, темні панелі `#0F1113`/`#23292C`, активна вкладка `#5A0F2C`/`#8C1C47`, неактивна `#2A0E18`/`#3A1422`, текст `#EDE3D2`, золотий `#E8D7A8`, другорядний `#CBBFA6`, серця `#F06A5A`, щити `#7FB4E8`.
- Шрифт заголовків — `var(--font-main)` (Cinzel). Увага: у Cinzel немає кирилиці; для укр. локалізації знадобиться запасний шрифт (напр. Cormorant SC).

## Фаза 2 — характеристики ростуть від прогресу у випробуваннях (ЧЕКАЄ РІШЕННЯ ОЛЕГА — не реалізовувати без підтвердження)

Ідея: кожна правильна відповідь у випробуваннях (зараз — Зал Знань, `knowledge.history`) непомітно накопичує досвід ігрової характеристики. Гравець бачить лише «Сила ранг 2 · ще 3 випробування».
Пропозиція відповідності (на затвердження):

| Характеристика                                                                                                                                                                                                                                                                                         | Що росте з рангом                        | Джерело досвіду (прихований)         |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------- | ------------------------------------ |
| Сила                                                                                                                                                                                                                                                                                                   | Атака, Поштовх                           | опановані факти множення             |
| Стійкість                                                                                                                                                                                                                                                                                              | Захист, макс. щити                       | опановані факти ділення              |
| Витримка Волі                                                                                                                                                                                                                                                                                          | місткість Волі (`effectiveWillCapacity`) | загальна кількість опанованих фактів |
| Розвідник                                                                                                                                                                                                                                                                                              | як зараз                                 | кроки по мапі                        |
| Відкриті питання: що означає «опанований факт» (напр. 3 правильні поспіль), скільки фактів на ранг, чи падає ранг при помилках, як це перенести на фізичну гру (доріжка рангу на картці героя). Логіка рангів — чиста функція в `packages/engine` (скіл `hexoflat-engine`), UI лише показує результат. |
